# Sleepy Clock 💤

A cute little clock with feelings. It gets sleepy when you should be sleeping too.

A lightweight Chrome/Chromium new-tab extension with a clock face that changes expression throughout your local day. Click its face to wake it up and toggle 12/24-hour format.

## Install
1. Open `chrome://extensions` and enable **Developer mode**.
2. Click **Load unpacked** and select this repository folder.
3. Open a new tab.

No backend, analytics, or network requests. Your preference stays in browser local storage.
